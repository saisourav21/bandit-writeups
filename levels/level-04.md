# Bandit Level 4 → Level 5

### Challenge

Find the password stored in the only human-readable file located inside the `inhere` directory.

### Commands Used

```bash
cd inhere/
file ./-*
cat ./-file07
```

Password found by using `file ./-*` to inspect all files in the directory and identify `./-file07` as ASCII text.
